# 신촌 소음데이터 처리 보고서

실행일: 2026-10-23. 전체 상세 해시와 파일별 ZIP member는 `data/processed/etl_report.json`에 보존했습니다.

## 1. 원본 목록과 범위

- S-DoT CP949 CSV 46개, 총 약 1.9GB, 2025-11-11~2026-10-11 파일명 범위입니다. 요청서에 기재된 “2026년 4~10월”보다 자료가 더 많았고, 2025-11부터 존재합니다. 2025-11-24~30과 2026-08-17~23 파일은 발견되지 않았습니다.
- 도로교통소음 ZIP 4개: 2021~2024 월별 48 workbook, 2025 상·하반기 각 6개, 2026 상반기 6개입니다.
- 별도 XLSX 1개: 성수동·시청역·신사역·신촌역 시트, 신촌역 자료는 2018-11-01~2019-03-05입니다.
- 도로자료 파일 5개의 총 크기는 약 3.1MB입니다.

## 2. 실제 컬럼과 파싱

S-DoT 헤더는 모두 동일한 59열 서명 1종이었습니다. `평균 풍속`, `최소 풍속`, `평균 흑구온도` 같은 중복 이름이 있으므로 이름 기반 dict 변환 대신 다음 위치와 이름을 동시에 검증했습니다: 모델명 0, 시리얼 1, 센서 시간 2, 자치구역 4, 행정구역 5, 최대/평균/최소 소음 24/25/26, 데이터수집시간 57, 데이터구분번호 58. 센서 시간은 `%Y-%m-%d_%H:%M:%S`로 읽어 `Asia/Seoul` aware datetime으로 저장했습니다.

도로 ZIP의 월별 workbook은 `신촌(시간별)` 시트, 행 4의 `측정 데이터: LEQ`, 행 6의 1~24시 헤더, 일별 24개 값 구조입니다. 별도 XLSX는 `년도/월/일/시간/측정지점/소음도/비고` 구조지만 지표 정의가 없어 `소음도_정의미제공`으로 분리했습니다.

## 3. 신촌 센서와 측정지점

필터는 정확히 `Seodaemun-gu`와 `Sinchon-dong`을 사용했습니다. S-DoT sensor_id/model은 `SDOT001`, 시리얼과 추출 행 수는 다음과 같습니다.

- `V02Q1940138`: 7,305행
- `V02Q1940422`: 7,038행
- `V02Q1940585`: 7,303행

센서 좌표·주소 메타데이터가 원본에 없어 창천동·대현동을 추가하지 않았습니다. 도로자료 측정지점 표기는 `신촌` 48,074행과 `신촌역` 3,001행입니다. 주소·좌표가 없으므로 개별 PoC 수음점의 실측으로 표시하지 않습니다.

- 신촌 추출: 21,654
- 유효 고유 집계 행: 14,335
- 파일 SHA-256 중복: 0개. 2026-08-10~16 파일은 한 개만 존재하며 모든 46개 해시가 다릅니다.
- 센서 시리얼+센서시간 논리 중복: 0개, 충돌 중복: 0개
- 센서 ID(model)+시간 키 중복 표시는 14,341건입니다. 세 장비가 동일한 `SDOT001` model ID를 공유하기 때문이며 같은 관측으로 간주해 제거하지 않았습니다.
- 데이터수집시간 중복 및 데이터구분번호+수집시간 중복 표시는 각각 8,688건입니다. 센서별 시리얼이 다를 수 있고 데이터구분번호 공식 정의가 없어 제거·우선순위를 적용하지 않았습니다.

- 센서시간 파싱 불가 8개. 원문과 사유를 `held`로 보존합니다.
- 음수 및 `min <= avg <= max` 위반: 0개
- 데이터구분번호: `1` 21,640행, 빈 값 6행, 파싱 불가 8행. 공식 정의가 제공되지 않아 우선순위를 적용하지 않았습니다.
- 정상 관측의 대표 간격은 60분 14,323회이며 120·300분 및 장기 공백도 있습니다.
- 센서별 전체 기간 시간격자 대비 유효 sensor-hour 확보율은 0.597590입니다. 이 값은 파일 공백과 센서 결측을 함께 반영합니다.

도로자료는 51,075행 모두 숫자·비음수였습니다. `LEQ` 48,074행과 정의 미제공 `소음도` 3,001행을 혼합하지 않았습니다.

## 5. 생성 파일과 프로파일

- `data/processed/sdot_sinchon_clean.csv` 약 9.1MB
- `data/processed/road_noise_sinchon_clean.csv` 약 19MB
- `data/processed/background_profile.csv` 96행
- `data/processed/etl_report.json` 처리 로그·해시·품질 통계

프로파일은 데이터셋별, 평일/주말별, 시간별 중앙값과 평균·관측수를 저장합니다. S-DoT과 도로 LEQ는 단순 평균하거나 합치지 않았습니다.

2025-01~2026-06 신촌 도로 LEQ 중앙값은 평일 기준 00시 70.2, 03시 67.1, 05시 66.4, 07시 70.9, 08시 71.5, 12시 71.3, 17시 71.55, 19시 71.6, 23시 70.7dB입니다. 시간당 관측 수는 390개입니다. 주말은 시간당 156개이며 00시 70.0, 05시 66.7, 08시 69.9, 12시 71.4, 19시 71.5dB입니다.

S-DoT 장치 평균소음 중앙값은 평일 38~41 범위, 주말 38~41 범위입니다. 그러나 음향지표 정의·교정·설치 위치가 확인되지 않아 물리 배경 합성에는 사용하지 않습니다.

## 6. 백엔드 사용 범위

- `assumed_demo`: 기존 기본값, 자동 유지
- `sdot_observed_profile`: 관측 기반 시간 패턴 분석용, `calculation_eligible=false`; 합성 요청은 422
- `road_traffic_observed_profile`: `LEQ`로 명시된 2025-01~2026-06 과거 시간별 중앙값. API에서 명시 선택할 때만 지역 대표 배경 후보로 사용

도로 프로파일도 2026-10-26 시연일의 실측값이 아니며, 주소·좌표가 없어 모든 수음점에 동일하게 적용되는 지역 대표 후보라는 품질 경고를 반환합니다. 기존 가정값을 자동 교체하지 않았습니다. 2021~2024는 과거 참고자료, 2018 별도 XLSX는 지표 정의 미확인으로 계산에서 제외했습니다.

## 7. 한계와 추가 필요자료

S-DoT 센서 좌표·설치환경·소음 단위 및 집계식, 데이터구분번호 정의, 도로 측정지점 주소·좌표·장비·교정정보, LEQ의 정확한 적분기간·가중특성 문서가 필요합니다. 이를 확보하기 전 법적 평가나 개별 수음점 실측으로 사용할 수 없습니다.
