## 변경 전후

변경 전 `final-demo-congestion`은 07:00~18:00 창, 9시간 작업안, 07:00~09:00 주변 소음 가정을 사용했다. 중첩은 수신점별 노출 지표로만 보고했고 대표 추천 선정에는 반영하지 않아 9/11 대표안이 `offset-0`이었다.

변경 후 시연 계산은 다음 사전식 순서를 사용한다.

1. 주변 공사와 신규 공사의 동시 고소음시간(`existing_high_noise_overlap_minutes`) 최소
2. 작업별 시작시각 변경량 합계 최소
3. 후보 ID 오름차순으로 결정적 동률 처리

주민 부담·Impact·수신점별 기존 소음 중첩 지표는 기존 방식대로 계산·보고하지만 대표 추천의 1·2순위와 섞어 합산하지 않는다. 후보는 기존 15분 간격 `offset-0`~`offset-120` 열거 방식을 유지한다.

동시 고소음시간은 `high_noise_task_ids`로 분류한 절단·깨기 공정과 `high_noise_event_ids`로 분류한 날짜 한정 주변 철거 가정의 실제 시간 교집합을 합산한다. 공통 수신점이 없는 이벤트와 신규 사업 ID가 같은 자기 이벤트는 제외한다. 행사·수거 등 표시용 이벤트는 이 지표에 포함하지 않는다.

## 시연 입력

- 일반 분석시간: 07:00~18:00
- 장비 허용시간 및 후보 배치 창: 08:00~17:00
- 원안: 08:00~15:00, 총 420분
- 공정: 콘크리트 절단 60분 → 포장 깨기 120분 → 터파기 180분 → 되메우기·다짐 60분
- 9/11 주변 철거 고소음: 08:00~11:00, 82 `Lp_dBA` 가정
- 10/7: 위 철거 이벤트 비활성(날짜 범위 밖)

08:00~11:00과 82 dB는 관측값이 아니라 공개 사업 ID·기간과 분리된 시연 가정이다.

## 25m 주거 계산 지점

`final-demo-congestion-near-residential`의 `assumed-residential-25m` 정의를 `final-demo-congestion`에 재사용했다. 학교 2곳과 병원 1곳은 유지했다. 이 지점은 공사 대표점에서 25m인 가상 방사거리 지점으로 위·경도와 실제 건물 좌표가 없으며, OSM 17~23m 후보를 사용하지 않았다. 기존 거리 감쇠·배경소음·장비 소음 계산과 주변 철거 평가에 포함된다.
