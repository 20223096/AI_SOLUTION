# M0/M1 비교

## 1. 비교 원칙

M0는 기존 기본 모델이며 변경하지 않았다. 장비가 슬롯과 겹치면 슬롯 전체에 전가동하고 기존 수음점-대표점 거리를 사용한다. M1은 명시적 좌표, 3차원 거리, 실제 가동분, 대수와 동시성 상태를 받는다.

`POST /api/noise/compare-m0-m1`은 같은 좌표·Lw·배경에서 M0를 명시적 100% 슬롯 가동으로, M1을 요청된 가동분으로 계산한다. 이 비교는 계산 세분화의 차이지 실제 정확도 평가가 아니다.

## 2. 검증용 비교 수치

조건: Lw 100 dB, 1대, 10m, 같은 높이, 배경 50 dB, 자유음장, M1 가동 5분/15분.

| 지표 | M0 전가동 | M1 5분 가동 |
|---|---:|---:|
| 신규 공사 기여 LAeq | 69.01 | 64.24 |
| 전체 합성소음 | 69.06 | 64.40 |
| 총소음 증가 | 19.06 | 14.40 |
| 65dB 기준 에너지-분 | 37.746909 | 12.582303 |
| legacy 증분 Impact | 22.97 | 14.10 |

M1이 4.77 dB 낮은 이유는 1/3 가동 에너지 평균 때문이다. 실측과 더 가까워졌다는 의미는 아니다. 실제 가동분이 틀리면 M1도 틀린다.

## 3. 연속 노출과 슬롯 LAeq

M0는 겹친 슬롯 전체를 활성으로 취급한다. M1은 실제 가동구간이 있으면 연속 노출과 동시 합성 최대레벨을 구분한다. 가동분만 알고 배치를 모르면 슬롯 용량을 만족하는 중첩·연속노출 범위를 반환한다. 총 source-minute가 슬롯 길이를 초과하면 완전 순차를 가능한 경계로 사용하지 않는다. 이 범위는 신뢰구간이 아니다.

## 4. 추천 일정과 Pareto

기존 추천과 Pareto는 계속 M0/`legacy_v1`/`robust_experimental_v1` 경로를 사용하므로 결과가 바뀌지 않았다. M1은 별도 음향 계산 API이며 기본 최적화 목적함수에 연결하지 않았다.

공식 공사는 좌표·일별 작업·가동률이 없어 M1 후보별 비교가 `deferred`다. 따라서 공식 데이터만으로 새 Noise Slot을 추천하거나 Pareto 변화가 있다고 보고하지 않는다. 동일한 장비·위치·가동률·배경이 모든 후보에 적용되는 가정 실험에서는 시간대별 배경/민감도 차이가 없다면 공사 단독 에너지도 같아 추천을 바꿀 근거가 없다.

향후에는 기존 optimizer가 선후행·자원·작업창을 만족하는 후보만 생성하고, 각 후보에 M1 슬롯 입력을 만든 뒤 다음 축을 독립적으로 비교해야 한다.

- 신규 공사 에너지 노출
- 민감시간 노출
- 연속 노출
- legacy 증분 Impact
- 일정 변경량

서로 다른 단위를 합산하지 않고 Pareto 관계를 계산해야 한다. 현 단계에서는 불완전한 공식 입력으로 추천을 강제하지 않는다.

## 5. 호환성

- 기존 `/api/noise/predict`: 변경 없음
- 기존 기본 모델 버전: `poc-0.1.0`
- 기존 점수: `legacy_v1`
- 기존 실험 지표: `robust_experimental_v1`
- 신규: `M1_physical_v1`
- M0 비교 표기: `M0_representative_point_assumption`
