# PRD 제약·추천 통합 테스트 결과

검증일: 2026-10-25. 기준 커밋: `18dde37`에서 시작.

## 결과

- 최종 수집 예시의 동적 계약 검증을 포함해 총 245개 pytest 통과. 요청 기준의 기존 234개 회귀 범위를 모두 포함한다.
- 기존 공개 API 25개 경로와 응답 모델 유지, 신규 2개 추가.
- 9/11 기본 결과: `offset-0`만 조건부 Pareto/추천, 가정 소음 마스킹 결과를 피해 감소로 해석하지 않음.
- 10/7 기본 결과: `offset-0` 13.72, `offset-120` 13.20, 민감 수음점 노출시간 동일.
- ×1.1/1.3/1.5 민감도 순위 회귀는 기존 테스트로 유지.
- 작업창을 09:00~18:00으로 명시한 사례에서는 `offset-120` 하나만 추천 가능.
- `cut`을 06:00~07:00 고정한 사례에서는 9개 후보가 모두 `fixed_task_start_changed`로 불가능하고 추천 없음.

## 검증 항목

HTTP 테스트는 정상 입력, 결측 초안, 장비 필요시간, 일 최대 대수, 동시 대수, 장비 허용시간, 도로점용, 고정 작업, 선후행, 당일 복구, 완료일, 전 후보 불가, 단일 후보 가능, 기존/조건부 결과 구분, 9/11·10/7 회귀, 422 오류, CORS, OpenAPI response schema를 포함한다.

후보 생성은 기존 15분 offset 집합만 사용한다. 통합 결과는 기존 optimizer의 전역 최적해가 아니라 명시 제약으로 필터링한 조건부 후보 집합이다.
