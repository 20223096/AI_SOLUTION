# Sprint 29 비교실험 결과

실행 명령:

```bash
PYTHONPATH=backend python3 scripts/run_sprint29_experiments.py --output /tmp/sprint29-results.json
```

환경: Python 3.14.4, macOS arm64, OR-Tools 9.15.6755, 15분 grid. 결과는 시뮬레이션이며 전역 최적성, 법적 적합성 또는 실제 피해 감소를 의미하지 않는다.

## 공통 지표 제한

- Noise Impact는 `incremental_impact_cost`다.
- 연속 고소음과 Quiet Window는 총환경 65 dB PoC threshold 기준이다.
- “동시 고소음시간”의 독립 wall-clock 지표는 아직 없다. 스크립트는 이 필드를 `null`로 기록하고, 별도로 `existing_noise_overlap_receptor_minutes`를 출력한다.
- 모든 아래 선택안의 제약 위반 수는 0이다.
- 9/11 existing-event는 시나리오 가정이고 10/7에는 해당 overlay가 없다.

## 기준 수치 보존

| 버전 | 9/11 | 10/7 |

기존 결과는 삭제·수정하지 않고 버전별로 병기한다.

## 입력 출처

- background: 과거 도로교통소음 시간대별 대표 LEQ
- S-DoT: 실제 관측이지만 합성 제외
- 장비/거리: 공식 참조, 대표점 파생거리, 시나리오 가정이 혼재
- 9/11 기존 공사: assumed overlay
- 공공 행사/공사: 날짜 문맥만 사용하며 음향 계산 미사용

## 재현성

스크립트는 코드 fixture를 수정하지 않고 JSON을 stdout 또는 지정 경로로 출력한다. 개선되지 않는 경우, `null` 지표, 동일 결과도 그대로 기록한다. 실행 환경과 엔진 버전을 결과 최상위에 포함한다.
