# 최종 시연 데이터와 한계

검증일: 2026-10-26

## 9/11과 10/7 회귀

| 분석일 | 결과 | 해석 제한 |
|---|---|---|
| 2026-09-11 | 원 일정 `offset-0` 유지 | 07:00~09:00 기존 공사 82 dB는 실제 관측이 아닌 날짜 한정 가정 overlay |
| 2026-10-07 | 제한된 9개 후보에서 `offset-120`의 Impact 13.72 → 13.20 | 전역 최적화나 실제 피해 감소가 아닌 모델 점수 trade-off |
| 공통 | 민감 수음점 노출 1,620 receptor-minutes 불변 | 가정 수음점·민감도 정책을 포함한 계산값, 주민 피해 관측값 아님 |

9/11 결과의 원 일정 유지는 더 조용하거나 안전하다는 현장 결론이 아니다. 10/7의 0.52 감소도 선택된 모델·배경 프로파일·후보 집합 안의 계산 결과일 뿐이다.

## 데이터 구분

- 관측: 도로 소음 대표 프로파일 등 출처가 있는 과거 관측. 해당 공사 현장·주민 외벽 실측이 아니다.
- 공식 정보: 공공 장비 인증 기록, 공식 주소 출입구 대표점. 실제 투입 장비·공사 선형·수음점이 아니다.
- 실험 가정: 일정, high-noise 분류, 민감도 가중, 기존 이벤트 시간·음향, 일부 거리와 시연 문의처.
- 파생값: M0/M1 시뮬레이션, Impact, 3단계 일정 activity, quiet interval.

주민 API의 `quiet/moderate/loud`는 dB 등급이 아니다. `quiet`은 예정 작업 없음, longest quiet interval은 high-noise 작업 없음으로 정의가 다르다. 주민 DTO에는 dB, Impact, 민감도, 수음점, 내부 위반 로그를 포함하지 않는다.

실제 공사 geometry, 실제 주거 외벽 수음점, 현장 장비·가동률·동시성, 수음점별 배경소음과 현장 검증은 여전히 확보되지 않았다.
