### 공공데이터포털 키 검증

현재 장비 수집기는 `requests`/`httpx` API 파라미터 호출이 아니라 공공데이터포털 검색 페이지 URL을 직접 내려받고 있었다. 목표인 국립환경과학원 **소음발생건설기기 소음도검사 현황(데이터 ID 3038414)**은 CSV 파일데이터이며 `serviceKey` 인증 API가 아니다.

연관 승인형 API인 **자동차 배출가스 및 소음인증 정보(데이터 ID 15000988)**의 공식 `getVems` 엔드포인트로 키를 실제 시험했다. `.env` 값은 공공데이터포털의 Encoding 키 형태였으므로 한 번 `unquote`한 뒤 `httpx.get(..., params={"serviceKey": ...})`에 넘겼다. 최종 요청에는 `%252B` 같은 이중 인코딩이 없음을 테스트했다.

실제 응답은 HTTP 403, 코드 `30`, `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`였다. 따라서 키 존재를 인증 성공으로 간주하지 않았으며, 이 키가 해당 API에 승인된 상태라고 확인할 수 없다. 결과는 `data/reports/data_go_kr_auth.json`에 키 없이 기록했다. 사용자가 실제로 신청·승인받은 API의 데이터 ID 또는 요청주소가 `15000988/getVems`와 다르다면 그 엔드포인트가 추가로 필요하다.

## 서울 Open API 호출 검증

- 건설알림이: `http://openapi.seoul.go.kr:8088/{KEY}/xml/pmisPjtList/{START_INDEX}/{END_INDEX}/`
- 문화행사: `http://openapi.seoul.go.kr:8088/{KEY}/json/culturalEventInfo/{START_INDEX}/{END_INDEX}/`
- 인증 방식: 경로의 `KEY`, 응답 형식과 서비스명, 시작·끝 인덱스가 필수다.
- 실제 결과: 두 서비스 모두 HTTP 200 및 `INFO-000`. 건설은 XML 루트 `PROJECT_LIST`, 문화행사는 JSON 루트 `culturalEventInfo`였다.
- 원본: 건설 6개 XML 페이지, 행사 20개 JSON 페이지를 각각 `data/raw/construction/`, `data/raw/events/`에 저장했다.
- 오류는 HTTP 401/403 `blocked_auth`, 비정상 서비스 결과코드 `source_unavailable`, 0건 `data 없음`, XML/JSON 파싱 실패 `response_format_error`, 네트워크 실패 `blocked_access`로 구분한다.

## 정규화 및 안전 규칙

- `Lw_dBA`와 `Lp_dBA`를 명시하지 않은 장비값은 계산에 넣지 않는다. 현재 장비값은 계속 `user_provided` 가정이다.
- 사업기간과 실제 일일 작업시간은 별도 열이며 전자로 후자를 추론하지 않는다.
- 행사 일자와 시각을 분리한다. dB와 실제 시각이 없는 공사·행사는 일정 맥락일 뿐 에너지 합산 대상이 아니다.
- WGS84 좌표와 CRS가 확인된 지점만 지오데식 거리 계산에 쓴다. 주소만 확인된 시설에는 좌표나 거리를 만들지 않았다.
- 주민 배출 가능 시간은 차량 운행·수거 시간으로 변환하지 않는다.
- 행사 중복 키는 `(명칭, 시작일, 종료일, 장소)`이다.
- `STRTDATE`/`END_DATE`의 `00:00`은 날짜 경계값이므로 실제 행사시각으로 사용하지 않는다. 실제 시각은 `PRO_TIME`을 원문 보존하고, 단일한 시각쌍만 `start_time`/`end_time`으로 정규화한다. 날짜별 시각쌍이 여러 개인 축제는 한 쌍으로 축약하지 않는다.

## PoC 통합과 데모 날짜

서울 일정 데이터 기준 시연 후보는 다음과 같다. 건설 건수는 해당 날짜가 사업기간 안에 든다는 뜻일 뿐 실제 당일 작업을 뜻하지 않는다.

| 후보일 | 사업기간상 공사 | 행사 | 시작·종료시각 모두 정규화된 행사 | 판단 |
|---|---:|---:|---:|---|
| 2026-08-01 | 2 | 2 | 1 | 단일일 행사 시각이 있어 일정 데이터 충실도가 가장 높음 |
| 2026-09-11 | 2 | 1 | 0 | 신촌글로벌대학문화축제가 있으나 날짜별 시각이 달라 원문만 보존 |
| 2026-10-20 | 1 | 1 | 1 | 기존 서강대 시험기간 비교와 함께 시연 가능하나 반복행사의 실제 요일 확인 필요 |
| 2026-12-15 | 1 | 0 | 0 | 서강대 기말시험 비교에는 유효하지만 서울 행사 일정은 없음 |

일정 데이터만 놓고 보면 **2026-08-01**이 우선 후보이고, 기존 시험기간 민감도 실험을 함께 보여주려면 **2026-10-20**을 보조 후보로 유지한다. `sinchon-public-2026-10`은 CASE A의 물리 조건을 유지하면서 서강대 공식 일정에서 파생한 대학 수음점 민감도만 적용한다. 이를 연세대·이화대 시험기간으로 표현해서는 안 된다.

2026-10-20 실제 실행 결과는 후보 9개, 실행 가능 9개, Pareto 1개, 추천 `offset-0`이다. 증분 영향비용 1515.85, 절대 영향비용 1523.35, 변경량 0분, 최대 연속 고소음 180분, Quiet Window 480분이다. 비교일 2026-11-02에는 영향비용이 각각 1464.90, 1472.40으로 낮아졌지만 추천은 바뀌지 않았다. 시험기간 민감도가 비용을 바꿨으나 원 일정이 계속 비지배 후보였다.

배경 프로파일은 역사적 대표 프로파일이다. 시연일이 관측일이라는 의미가 아니며 S-DoT는 분석 전용, 도로교통 프로파일만 기존 정책에 따라 물리 합성 가능하다.

## 실제값·가정값과 한계

공식 API에서 건설 사업 3건과 문화행사 55건을 신촌권 일정으로 확인했다. 다만 건설 사업기간은 실제 일일 공정이 아니며, 행사에도 음향값이 없다. 따라서 이 자료는 충돌 경고·달력 표시·후보 설명에는 사용할 수 있지만 dB 에너지 합산이나 기본 최적화 목적함수에는 자동 투입하지 않았다. 시험기간 여부는 공식 일정에서 `derived`되지만 민감도 가중치 자체는 PoC 정책 가정이다. 장비 소음, 일일 공정, 공사원과 수음점 거리, 주거 수음점, 기존 혼잡 이벤트 소음은 여전히 가정 또는 미확보다.

## 추가로 필요한 사용자 작업

1. One-PMIS 주간작업 또는 현장 일보에서 실제 날짜·작업 시작/종료시각을 추가 확보한다.
2. 문화행사의 날짜별 `PRO_TIME`을 별도 일정 행으로 펼치는 정책을 검증한다.
3. 장비 모델, Lw/Lp, 측정거리·운전조건이 함께 있는 국립환경과학원 원문 표를 제공한다.
4. 공사원 WGS84 좌표와 기관 공식 좌표/CRS를 제공한다.
5. 차량 운행 시각이 포함된 서대문구 수거 원자료를 확보한다.
6. 대상 필지 또는 사업구간과 공식 용도지역 경계 파일을 제공한다.

각 원천의 이용약관과 호출 제한을 재확인해야 한다. 원본 디렉터리는 개인정보·대용량 유입을 막기 위해 Git에서 제외하고 정규화 CSV와 매니페스트만 버전 관리한다.
