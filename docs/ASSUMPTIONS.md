# 가정과 한계

## 6차 공공데이터 연동

- 공식 주소만 확인된 시설에는 좌표나 공사원과의 거리를 임의 생성하지 않는다.
- `sinchon-public-2026-10`의 날짜는 서강대 공식 일정에서 파생했지만 민감도 가중치는 PoC 정책 가정이다.
- 공사·문화행사·폐기물 일정은 음향값과 실제 일일 시각이 확인되기 전까지 dB 합산에서 제외한다.
- 공식 장비 Lw/Lp 자료가 미확보되어 기존 장비값의 `user_provided` 상태를 유지한다.
- 시연 날짜와 배경소음 관측기간은 다르며 대표 프로파일을 해당 날짜의 실측값으로 표현하지 않는다.

- 113/122/100/102 dB(A)는 사용자가 제공한 시연용 **음향파워 가정값**이며 공식 검증값이 아닙니다.
- 덤프트럭 값은 누락 상태이며 숫자를 임의 생성하지 않고 계산에서 제외하며 경고합니다.
- 30/50/100 m 수음점 거리, 배경 LAeq, 민감도, 300 m 반경, 65 dB 분석 임계값은 PoC 가정입니다.
- 공사기간의 월 범위를 JSON 날짜로 표현하기 위해 월 첫날/말일을 사용하되 원문도 보존합니다.
- 관 교체·포장 복구 등 미제공 공정시간은 null입니다. 알려진 장비시간 540분만 배치하며 완전한 현장 하루 일정이라고 주장하지 않습니다.
- 자유음장 계산은 반사·차폐·지면·건물·방향성·기상을 반영하지 않습니다.
- 예상 모델값은 법령의 측정·평가값이나 적합/위반 판정이 아닙니다. 적용 법령·지역·특례가 미확정이므로 `legal_assessment=null`입니다.
- 기존 행사/수거 데이터 파일은 교체 가능한 인터페이스입니다. 기본 CASE A에는 입력 이벤트가 없고, 실험 B에만 명시적 가상 이벤트가 있습니다.
- 실험 B의 기존 공사 82 dBA, 수거 75 dBA와 중첩 receptor-slot당 30점 정책부담은 모두 `assumed`입니다. 실제 관측값이나 검증된 건강영향 계수가 아닙니다.
- 실험 C의 08:00~10:00 시험시간과 +0.5 민감도도 `assumed`이며 실제 대학 학사일정이 아닙니다.
- `road_traffic_observed_profile`은 2025-01~2026-06 신촌 LEQ의 시간대별 중앙값(`derived`)이며 2026-10-26 직접 실측이 아닙니다. 주소·좌표가 없어 세 가상 수음점에 같은 지역 대표값을 적용하지만 각 수음점의 실측이라고 표현하지 않습니다.
- 기본 주민 목적함수는 신규 공사 포함 Impact에서 동일 슬롯의 기존환경 Impact를 뺀 실험용 증분값입니다. 기존 절대 Impact도 병렬 보존합니다. 어느 값도 실제 건강피해 또는 법적 기준이 아닙니다.
- MockExtractor는 결정적 규칙 기반 테스트 구현이며 실제 AI가 아닙니다. LLM 전송 계층은 제공업체 확정 후 구현해야 합니다.
