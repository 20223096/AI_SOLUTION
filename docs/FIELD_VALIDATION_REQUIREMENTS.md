# 현장 검증 요구사항

## 1. 현재 상태

현장 실측자료가 없으므로 `validation_status=not_evaluable`이다. 검증용 가정 데이터나 합성값을 실제 정확도 평가에 사용하지 않는다.

## 2. 필요한 현장 입력

### 공간

- 공사 선형과 작업구간별 좌표, CRS
- 슬롯별 실제 장비 위치 또는 이동 경로
- 수음점 좌표·높이·건물 면 위치
- 음원 높이, 방음벽 위치·높이, 주변 건물 형상

### 장비와 운전

- 제작사, 모델, 일련/승인 식별자
- 장비 대수와 결합 장비
- 슬롯별 배치시간, 실제 운전 시작·종료, 부하·작업모드
- 동시가동 기록과 공정 선후행
- 덤프트럭 통과대수·속도·경로
- 펌프 연속/간헐 운전기록

### 음향 측정

- 동일 수음점·동일 15분 또는 합의된 평가시간의 LAeq
- 장비 단독/복합 운전 구분이 가능한 로그
- 배경 측정과 공사 포함 측정
- 계측기 등급, 교정 전후 기록, 마이크 높이
- 기상, 지면, 차폐, 반사 조건
- 충격성 평가가 필요하면 합의된 추가 지표와 측정 설정

## 3. 정렬과 품질검사

예측과 실측은 같은 수음점, 좌표/높이, 시간구간, 음향지표, 주파수·시간가중 조건으로 정렬해야 한다. 다음 경우 비교에서 제외하거나 별도 표시한다.

- 시간대가 불일치
- LAeq와 Lmax 등 지표가 다름
- 배경 포함 여부가 다름
- 장비 가동 로그가 없음
- 교정 또는 기상자료가 누락됨
- 수음점이 이동했거나 위치를 확인할 수 없음

## 4. 평가 지표

정렬된 오차 `ei=예측-실측`에 대해 다음을 계산할 준비가 되어 있다.

- `MAE = mean(|ei|)`
- `RMSE = sqrt(mean(ei²))`
- `Bias = mean(ei)`
- 수음점별 MAE/RMSE/Bias
- 장비 단독 운전 표본이 충분한 경우 장비별 MAE/RMSE/Bias

측정값 배열이 비어 있으면 숫자 0을 반환하지 않고 `not_evaluable`을 반환한다. 장비별 평가는 실제 단독 또는 식별 가능한 운전 표본이 있어야 한다.

## 5. 검증 단계

1. 입력·계측 QA와 시간 동기화.
2. 자유음장 기본식만 사용한 사전등록 예측.
3. 수음점/장비별 잔차 확인.
4. 지면·차폐·대기·반사 보정의 근거별 독립 검증.
5. 보정 전후 성능을 별도 버전으로 보고.
6. 다른 날짜·구간의 보류 표본으로 재검증.

현장값에 맞추기 위해 같은 자료에서 계수를 조정하고 정확도를 평가하면 과적합이 된다. 보정자료와 검증자료를 분리해야 하며, 표본 수와 조건 범위를 함께 보고해야 한다.
