# 공간·장비 소음 데이터 검증 보고서

## 1. 대상 공사 위치

대상은 서울시 건설알림이 사업코드 `6132026083144`, **연세로2나길 20 일대 외 1개소 하수관로 개량공사**다. 서울 열린데이터광장 `pmisPjtList` 실제 응답에서 `LAT=37.5569842`, `LNG=126.9384049`를 확인했다. `OFFICE_ADDR`와 `PJT_SCALE`은 비어 있었으며 선형 구간, 시작·종료점, 지도 URL은 제공되지 않았다. 건설알림이 계약현황에서는 공사명, 발주기관 서대문구, 계약기간 2026-08-31~2026-12-18을 재확인했다.

따라서 좌표는 **공식 WGS84 대표점**으로 채택하되 실제 공사구간 전체나 연세로2나길 20의 건물점이라고 단정하지 않는다. 주소는 공사명의 위치 문자열만 보존했고 구조화된 공식 주소로 승격하지 않았다. VWorld 키를 요구하는 지오코딩이나 좌표 추측은 수행하지 않았다.

## 2. 수음점별 거리

공사 대표점과 시설 API의 공식 대표점을 WGS84 haversine으로 계산했다. 결과는 `data/processed/receptor_distances.csv`가 정본이다.

| 수음점 | 공식 좌표 (위도, 경도) | 수평 직선거리 |
|---|---|---:|
| 서울창서초등학교 | 37.55814305, 126.9334809 | 452.8 m |
| 창천중학교 | 37.55498958, 126.9392951 | 235.3 m |
| 연세대학교의과대학세브란스병원 | 37.5623446, 126.9408265 | 633.1 m |

시설 좌표는 건물·기관 대표점이며 실제 교실, 병실 창, 건물 외벽 수음점이 아니다. 거리도 지형, 건물 차폐, 고도, 회절을 반영하지 않은 수평 직선거리로서 보행거리나 실제 소음전파거리와 동일하지 않다. 공사 선형이 확보되면 대표점 거리를 폐기하고 선분/폴리라인 최단거리로 재계산해야 한다. 이번 구현에는 WGS84 선분 최단거리 함수와 테스트를 추가했지만, 실제 선형이 없어 대상 결과에는 적용하지 않았다.

## 3. 실제 좌표와 기존 가정값

기존 `case-a` 등 모든 시나리오의 30/50/100m 가정거리는 변경하지 않았다. 별도 `sinchon-spatial-2026` 시나리오만 공식 좌표 기반 452.8/235.3/633.1m를 사용한다. `/api/poc/scenarios/sinchon-spatial-2026`에서 좌표, CRS, 좌표 출처, 거리 방식, `verified_public` 상태를 조회할 수 있고 `/api/public-data/catalog`은 원본 거리행과 공식 장비 카탈로그를 함께 반환한다.

## 4. 장비별 공식 소음값

공공데이터포털 데이터 ID 3038414의 2026-04-20 ZIP을 내려받아 실제 CSV를 확인했다. 기간은 2008-01~2025-07이며 각 파일 열은 제작회사, 승인번호, 모델명, `음향파워레벨(dBA)`다.

| 대상 장비 | 확보 | 공식 모델별 행 | 판정 |
|---|---:|---:|---|
| 콘크리트 절단기 | 예 | 31 | `Lw_dBA`, 모델별 조회 가능 |
| 브레이커 | 예 | 198 | `Lw_dBA`, 모델별 조회 가능 |
| 굴착기 | 예 | 405 | `Lw_dBA`, 모델별 조회 가능 |
| 롤러 | 예 | 119 | 다짐기계 파일에 롤러 승인기록 포함 |
| 덤프트럭 | 아니오 | 0 | 자료 대상 9종에 없어 수치 생성 금지 |

정제 결과는 `official_equipment_noise.csv` 753행이다. 원문은 모델별 법정 소음도검사 값이지만 개별 행에 운전모드, 측정거리, 측정기하가 없다. 서로 다른 모델을 평균해 대표값을 만들지 않았다. 현재 시나리오 장비에는 모델명·승인번호가 없으므로 기존 113/122/100/102 dB 값의 상태는 계속 `user_provided`; 덤프트럭은 `missing`이다.

## 5. 백엔드 계산 반영과 새 시나리오

`sinchon-spatial-2026`, 분석일 2026-10-26, `assumed_demo`, 증분 목적함수를 실제 실행했다. 후보 9개/실행 가능 9개/Pareto 1개이며 추천은 원 일정 `offset-0`이다. 증분 영향비용 264.88, 절대 영향비용 264.88, 변경량 0분, 최대 연속 고소음 0분, Quiet Window 660분, 최대 Impact 15.23이었다. 활동 슬롯의 최대 총소음은 창서초 59.69dB, 창천중 64.14dB, 세브란스 58.00dB였다.

기존 `case-a`는 같은 실행에서 후보 9/9/Pareto 1, 증분 영향비용 1464.90, 절대 영향비용 1472.40, 최대 연속 고소음 180분, Quiet Window 480분이었다. 변화는 더 긴 공식 대표점 거리와 수음점 유형 차이에서 나온다. 이것은 좌표 기반 시나리오가 더 정확한 현장 예측이라는 뜻이 아니라 대표점 거리의 영향만 분리한 비교다. 배경소음과 장비 모델·운전조건은 여전히 가정이다.

## 6. 검증 결과

공사 좌표 범위 검증, haversine 거리, 선분 최단거리, 좌표 누락 시 실패/보류, 가정·검증 거리 분리, Lw/Lp 명시, 출처 유지, 기존 계산 회귀 테스트를 추가했다. 전체 결과는 **71 passed**이며 Python 컴파일 검사도 통과했다.

## 7. 남은 데이터와 한계

- 실제 2개소 공사구간의 시작·종료점 또는 폴리라인과 좌표 CRS
- 각 시설의 실제 평가 외벽·층·창 위치 및 표고
- 현장 투입 장비의 제작사·모델명·승인번호·동시 운전대수
- 검사성적서의 운전상태, 측정기하와 현장 작업 duty cycle
- 지형·건물 차폐, 지면흡음, 방음벽과 기상 조건
- 사업기간이 아닌 일자별 공정 및 실제 작업시간

공식 좌표와 모델별 검사 카탈로그는 계산 준비가 되었지만, 위 현장정보 전에는 법적 평가나 실측 대체로 해석할 수 없다.
