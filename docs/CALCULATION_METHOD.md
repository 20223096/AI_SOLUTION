# 계산 방법

## 음향

음향파워 `Lw`를 자유음장 점음원으로 가정해 `Lp = Lw - 10 log10(4πr²) + C`로 추정합니다. `C=0 dB`, `r>0 m`입니다. 반사, 차폐, 지면, 건물, 방향성, 기상은 미반영입니다. 이는 Lw와 Lp를 동일 취급하지 않습니다. 소음원 및 배경 결합은 `10 log10(Σ10^(Li/10))`입니다. 서로 같은 60 dB 두 소음원은 63.0103 dB가 됩니다.

배경은 수음점·시간별 LAeq 인터페이스이며 현재 시계열은 `assumed`입니다. 예측 Lp와 배경 LAeq 결합은 PoC 노출 비교용 근사이고 법정 평가가 아닙니다.

## 민감도와 영향점수

시간 가중치는 주간 1.0, 05~07/18~22시 1.5, 22~05시 2.0입니다. 시험기간 대학 +0.5, 주말 주거 +0.3, 학교·병원 인근 +0.5입니다. 모두 실험 가정이며 물리 dB에는 더하지 않습니다.

영향점수는 0~100의 실험 지표입니다. 각 성분을 [0,1]로 절단한 뒤 `100 × (0.45 level + 0.20 duration + 0.15 continuous + 0.15 sensitivity + 0.05 cumulative)`로 계산합니다. level은 `(L-total - threshold + 10)/30`, duration은 `분/480`, continuous는 `분/180`, sensitivity는 `((weight-1)/1.5) × level`, cumulative는 `부담/100`입니다. 민감도는 물리 dB를 바꾸지 않고 노출 정도에만 곱합니다. 절단 때문에 입력 증가 후 같은 점수가 될 수 있지만 감소하지 않습니다.

## 최적화와 비교

15분 단위 가능한 시작 오프셋을 열거하고 순차 배치하여 기간 보존, 선행관계, 공용 자원 비중첩, 허용 창, 금지시간, 당일 제한을 검사합니다. 기간 축소나 병렬 작업은 만들지 않습니다. 작은 PoC의 1차 경로는 정확 열거이며 OR-Tools는 향후 대규모 제약 확장 의존성으로 포함했습니다.

Pareto 축은 주민 영향비용과 원 일정 대비 각 작업 시작 변경분 합계입니다. 기본 주민비용은 모든 수음점·슬롯의 영향점수 합계입니다. 소음 집중 실험은 별도 `assumed` 정책항인 기존소음 중첩부담도 주민비용에 더하며 기본 Impact와 분리해 응답합니다. 다른 후보가 두 축 모두 같거나 낫고 하나 이상 엄격히 좋으면 제거합니다. distinct 후보가 하나면 세 이름으로 복제하지 않고 한 후보에 해당 성격을 함께 표시합니다.

고소음은 별도 분석 임계값(기본 65 dB) 이상입니다. 최대 연속 고소음, 분석 구간 내 가장 긴 임계값 미만 Quiet Window, 민감시간 노출, 최대/누적 영향, 변경분을 동일 날짜·수음점·규칙으로 비교합니다. 법정 기준 설정은 별도이며 현재 미확정입니다.
