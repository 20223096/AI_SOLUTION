# 공식 설계 기반 소음 시뮬레이션

## 1. 목적과 상태

`design-noise-simulation-v1`은 나라장터 공고 `R26BK01661205`의 공식 설계 사실을 보존하면서, 별도 거리조건과 시간 가정으로 M1을 실행하는 **설계 기반 시뮬레이션**이다. 공식 현장 예측이 아니며 `official_field_prediction_status=deferred`, `validation_status=not_evaluable`을 유지한다.

기존 M0/M1, `legacy_v1`, `robust_experimental_v1`과 기본 API는 변경하지 않았다. 신규 API는 다음처럼 분리했다.

- `GET /api/noise/design-simulation/catalog`: 공식 설계 사실, 검사자료 매칭, 누락 입력
- `POST /api/noise/design-simulation/reschedule`: 명시적 거리조건을 사용하는 부분 음향 시뮬레이션

## 2. 사용한 공식 설계 사실

| 구간 | 관경 | 연장 | 공식 geometry | 출처 |
|---|---:|---:|---|---|
| 연세로2나길 20 일대 | D450mm | 328m | `null` | 공사설명서 표 1 및 위치도 BIN0001.bmp |
| 충정로 35-17 일대 | D600mm | 155m | `null` | 공사설명서 표 1 및 위치도 BIN0002.bmp |

총연장은 483m다. 물량내역서의 포장절단, 포장깨기, 관 철거, 굴착, 되메우기·다짐, 하수관 부설, 포장복구, 토사·폐기물 운반, 물푸기 항목과 원 수량·단위·셀 위치를 API catalog에 그대로 반환한다. 이 수량은 프로젝트 전체 물량이며 두 구간에 임의 배분하거나 시간으로 환산하지 않는다.

대표 예시는 다음과 같다.

- 아스팔트/콘크리트 포장절단: 1,095m / 198m
- 기계터파기 굴삭기 0.2/0.4m³: 956m³ / 128m³
- 흄관 부설 D450/D600: 345m / 173m
- 램머 포함 관주위 되메우기·다짐: 283m³ / 60m³
- 물푸기 디젤펌프: 328hr — 일일 작업시간으로 해석하지 않음

공식 기간 140일, 작업 67일, 터파기·되메우기 31일, 관 부설 31일, 포장 5일은 사업계획 메타데이터다. 날짜별 확정 공정표로 쓰지 않았다.

## 3. 공간정보 검토와 구간 분리

공사설명서 위치도와 공개 주소 검색을 재검토했다. 공개 검색은 [서대문구 사업목록](https://lks5545.sdmcouncil.go.kr/CLRecords/Files/FileAppendix/a9/A012960.pdf)에서 사업명·D450~600·L=483m를 확인하고, 충정로 35-17이 특정 건물 주소라는 보조 정보는 확인할 수 있었다. 그러나 주소 대표점은 155m 또는 328m 관로 선형, 작업면 위치, 수음점까지의 거리를 확정하지 않는다. 검색 결과에서 연세로2나길 구간의 공사 선형도 확보하지 못했다.

따라서 공식 `geometry=null`, `representative_point=null`은 그대로다. 시뮬레이션 요청은 `distance_m`를 명시해야 하며 응답의 `simulation_geometry`는 `(0,0)` 음원과 `(distance,0)` 수음점을 둔 EPSG:5186 형식의 **로컬 상대좌표 가정**이다. 지적·지도 좌표가 아니다.

두 구간은 서로 다른 `receptor_set_id`와 `${segment_id}-simulation-background`를 사용한다. 요청의 `receptor_segment_id`가 구간과 다르면 422로 거부한다. 신촌 수음점이나 배경을 충정로 구간에 재사용하지 않는다.

## 4. 공식 장비 검사자료 매칭

753건은 모두 Lw dB(A)이고 법정 건설기계 소음검사 레코드다. 실제 운전모드와 측정 geometry가 행에 없으므로 현장값이 아닌 `official_reference_noise`다.

| 설계 장비 | 검사자료 | 최소/중앙/최대 Lw | 사용 여부 |
|---|---:|---:|---|
| 콘크리트 절단기 | 31건 | 97/113/121dB | 중앙값을 부분 시뮬레이션 참고값으로 사용 |
| 브레이커 | 198건 | 102/122/132dB | 중앙값 사용 |
| 굴삭기↔검사 굴착기 | 405건 | 79/100/114dB | 종류 유사 참고 중앙값 사용 |
| 롤러/다짐기계 | 119건 | 91/102/113dB | 설계 다짐기가 롤러인지 불명확하여 미사용 |

CSV에는 버킷 용량 필드가 없다. 모델명의 `20`, `40`, `70` 같은 숫자를 0.2/0.4/0.7m³로 해석할 근거가 없으므로 굴삭기 규격별 레코드를 분류하거나 섞지 않았다.

램머 80kg, 덤프트럭 2.5/4.5/15/24t, 디젤펌프 D150mm 20hp, 관부설 장비, 포장장비는 매칭값이 없다. 다른 장비값으로 대체하지 않았으며 모든 후보에 `acoustic_completeness=partial`과 `missing_noise_equipment`를 반환한다. 따라서 결과는 전체 공사소음이 아니다.

## 5. 시뮬레이션 가정

검증용 기본 입력은 공식 자료가 아니다.

- 거리: 연세로 구간 예시 30m, 충정로 구간 예시 50m
- 배경: 각각 55dB, 60dB
- 작업창: 07:00~18:00
- 민감시간: 08:00~11:00
- 공정 소요분: 절단 60, 깨기 90, 굴착 120, 관부설 90, 되메우기 75, 다짐 45, 복구 60
- 일반 공법 가정 순서: 절단→깨기→굴착→관부설→되메우기→다짐→복구
- 공식 참고 장비 가동률: 각 슬롯 배치시간의 50%

가정 공정시간은 설계수량이나 31/31/5일을 환산한 값이 아니다. 실제 작업시간, 교통개방, 장비 자원, 현장 선후행이 확보되면 교체해야 한다.

## 6. 구간별 계산 예시

같은 시간 가정에 대해 거리와 배경만 명시적으로 달리한 결과다.

| 구간/조건 | 원 일정 부분 에너지 | 최대 동시 합성 | 추천 참조 | Pareto 수 |
|---|---:|---:|---|---:|
| 연세로, 30m, 배경 55dB | 2200.759908 | 81.49dB | C 고소음 60분 지연 | 2 |
| 충정로, 50m, 배경 60dB | 792.414405 | 77.06dB | C 고소음 60분 지연 | 2 |

거리 차이에 따른 계산 차이이지 실제 두 현장의 비교가 아니다. 실제 좌표·수음점·배경이 없으므로 두 결과로 주민 노출이나 정확도 개선을 주장할 수 없다.

## 7. 데이터 품질 계약

응답은 다음을 독립 보존한다.

- `official_design_data`: 주소, 관경, 연장, 프로젝트 전체 설계수량
- `official_reference_noise`: 공식 검사 분포와 참고 중앙값
- `derived`: M1 슬롯 LAeq, 부분 에너지, Pareto 포함 여부
- `simulation_assumption`: 거리, 상대좌표, 배경, 시간, 가동률, 순서, 민감시간
- `missing_required_inputs`: geometry, 독립 수음점, 실제 장비·운전, 누락 장비 소음, 확정 일별 공정

현장 적용 전에는 두 구간의 GIS 선형, 구간별 주거 수음점, 실제 장비 모델, 슬롯 가동로그, 일별 작업계획, 수음점별 배경 및 동기화 실측이 필요하다.
