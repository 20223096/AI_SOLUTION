# 최종 시연 시나리오

## 공통 원칙

최종 시연은 기존 `case-a`와 `sinchon-spatial-2026`을 변경하지 않고 오버레이로 구성한다. 분석 구간은 07:00~18:00, 슬롯은 15분, 고소음 분석 임계값은 65dB이며 법정 판정 기준이 아니다. 기본 최적화 목적은 `incremental_impact`와 일정 변경량이다.

공식 도로소음 프로파일은 특정 관측지점의 역사적 대표 패턴이며 세 수음점에서 각각 측정한 값이 아니다. 현재 구현은 같은 시간값을 모든 수음점에 적용한다. S-DoT는 물리 합성에 사용하지 않는다.

## A. `official_reference_equipment`

- 분석일: 2026-10-26
- 권장 요청 프로파일: `road_traffic_observed_profile`
- 공사 대표점: 서울시 `pmisPjtList` 공식 좌표
- 수음점: 창서초·창천중·세브란스 공식 대표 좌표
- 거리: WGS84 대표점 간 직선거리
- 배경: 도로교통소음 관측 대표 프로파일
- 공공 일정: 서울시 공사·행사 카탈로그에만 표시하며 음향 합성하지 않음

장비는 데이터 ID 3038414의 동일한 `Lw_dBA` 열에서 장비 유형별 분포의 중앙값을 계산한 뒤, 중앙값과 정확히 일치하는 실제 관측행을 결정적으로 선택했다. 평균·보간값을 만들지 않았다.

| 장비 | 관측 수 / 고유 모델 수 | 단위 | 최소/중앙/최대 | 선택한 실제 모델·값 |

모든 행의 공통 측정조건 표기는 “법정 건설기계 소음도검사”이다. 원본 행에는 운전모드·측정거리·측정기하가 없으므로 그보다 세부적인 조건 일치 여부는 검증할 수 없다. 단위와 자료 계열이 같은 유형 내부에서만 분포를 만들었고, 중앙값 동률이면 CSV 원본 순서상 첫 실제 행을 택했다. 평균·보간이나 서로 다른 단위의 환산값은 만들지 않았다. 따라서 선택값은 **종류별 공식 검사자료 참고값**이지 실제 현장 투입모델의 값이 아니다. 덤프트럭은 원자료 대상에 없어 `missing`이며 계산에서 제외한다.

## B. `final-demo-congestion`

- 분석일: 2026-09-11
- 공간·장비·배경: A와 동일
- 실제 맥락: 서울시 사업 `7042025092297`의 사업기간이 분석일과 겹침
- 가정 이벤트: 07:00~09:00, 82 `Lp_dBA`, 세 수음점에 적용

사업명과 사업기간만 공공자료다. 실제 일일 작업 여부·시간·소음레벨은 확인되지 않았으므로 이벤트 전체 provenance를 `assumed`로 두었다. 원본 공공 일정과 이 실험 이벤트는 별개다. 이 가정은 특정 현장의 실측이나 민원 사실로 표현하면 안 된다.

시간 조정 후보 9개를 탐색했지만 개선 추천은 나오지 않았다. 높은 기존소음과 Impact 절단에서 공사를 겹칠수록 계산된 증분 Impact가 작아지는 마스킹이 발생했고, 원 일정은 변경량도 0이어서 다른 후보를 지배했다. 회피를 강제하는 정책비용은 증분 Impact와 이중 계산될 수 있어 임의 추가하지 않았다.
