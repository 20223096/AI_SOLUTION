## 화면 구성 → 연결할 데이터
| 시안 부분 | 연결할 값 (`published` 안) |
| --- | --- |
| 상단 남색 헤더: 날짜 · 주소, "오늘 우리 동네 공사 안내" | `location` (날짜는 분석일 2026-09-11) |
| 오늘 한눈에 ① 시끄러운 작업 시간 | `hourly_noise_levels` 중 label이 "시끄러움"인 구간의 처음~끝 |

| 시간대별 색 막대 (1시간 1칸) | `hourly_noise_levels`의 label → 시끄러움 `#D9604C` / 보통 `#E9A23B` / 조용 `#5AA47E` |
| 오늘 작업 일정 목록 (시간순) | `today_schedule` (작업명 옆에 시끄러움·보통 글자) |

## 꼭 지킬 것
- 문구는 "오늘 이 공사가 쉬어가는 시간"이 아니라 **"시끄러운 작업이 없는 시간"**이에요. 계산이 "시끄러운 작업이 없는 구간"이라, 터파기 같은 보통 작업은 그 시간에 있을 수 있어요.
- 화면 속 숫자는 시안 예시예요. 실제 값은 API 결과를 써 주세요.
- 오른쪽 위 "시연 예시" 표시는 지금처럼 `data_classification === 'demo'`일 때만 보여 주세요.
