# M1 시간 제약 검증

## 1. 발견된 오류

10차 구현은 15분 슬롯에서 10분 장비 두 대를 `sequential_possible`로 계산해 동시 합성 최대레벨의 하한을 69.01 dB로 제시했다. 총 가동량은 20 source-minute이므로 완전 순차 배치는 물리적으로 불가능하다.

두 장비 가동시간 `a`, `b`, 슬롯 길이 `T`에 대해:

- 최소 중첩: `max(0, a+b-T)`
- 최대 중첩: `min(a,b)`
- 완전 순차 가능: `a+b <= T`

## 2. 수정 결과

| 사례 | 최소 중첩 | 최대 중첩 | 완전 순차 | 최소 필요 동시 대수 |
|---|---:|---:|---|---:|
| 10분+10분 / 15분 | 5분 | 10분 | 불가 | 2 |
| 5분+5분 / 15분 | 0분 | 5분 | 가능 | 1 |
| 15분+15분 / 15분 | 15분 | 15분 | 불가, 완전 동시 필수 | 2 |

동일 69.01 dB 음원 두 대의 10분+10분 사례는 다음과 같이 수정됐다.

- 슬롯 LAeq: 70.26 dB — 가동 에너지 총량이 같아 변경 없음.
- 수정 전 잘못된 순차 피크: 69.01 dB.
- 수정 후 가능한 동시 합성 최대레벨: 72.02 dB.
- `sequential_possible` 요청: 실행 불가능으로 HTTP 422.
- `overlap_unknown`: 최소 5분/최대 10분 중첩과 72.02 dB 경계를 반환.

## 3. 정확한 구간과 미확정 구간

`exact`는 명시적 시작·종료를 sweep하여 실제 동시 음원 수, 실제 쌍별 중첩분, 동시 합성 최대레벨과 최대 연속 공사소음 구간을 계산한다. 07:00~07:10과 07:05~07:15는 실제 중첩 5분, 연속 공사소음 15분이다.

미확정 모드는 쌍별 최소/최대 중첩과 전체 `ceil(Σti/T)` 최소 필요 동시 대수를 반환한다. 3개 이상에서는 총 가동량만으로 어떤 고레벨 장비끼리 겹치는지 확정할 수 없다. 따라서 완전 동시 상한과 평균에너지/단일 최고음원 기반 피크 하한을 제공하지만, 달성 가능한 정확한 최소 피크라고 표시하지 않는다.

## 4. 레벨 명칭

- `slot_laeq_dba`: 15분 에너지 평균 공사 기여 레벨.
- `maximum_concurrent_combined_level_db`: 모델이 계산한 동시 활성 음원의 에너지 합성 최대값.
- `measured_lafmax_dba`: 실제 시간가중 소음계 측정값이 있을 때만 사용하며 현재 `null`.
- `max_simultaneous_lp_db`: 하위 호환을 위한 이전 필드명.

동시 합성값은 시간가중·계측기 응답을 모사한 LAFmax가 아니다.

## 5. 테스트

자동화 테스트는 10+10, 5+5, 15+15, 실제 5분 중첩, 미확정 범위, 3대 30 source-minute/최소 동시 2대, 비현실적 순차 요청 차단을 검증한다.

11차 완료 시 전체 `pytest` 결과는 기존 128개를 포함해 **140 passed**다. Python 컴파일, M0/M1 예측·후보평가·현장검증 API 스모크와 `git diff --check`도 통과했다.
